## Overview

React + TypeScript property website for Tanzania: rental and villa listings, booking availability calendar, villa sales, property management pages and a blog.

## Features

- Rental and villa listings with image galleries and detail modals
- Availability calendar per property
- Villa sales and property management service pages
- Blog with post pages
- Mobile menu, floating contact button, thank-you flow

## Tech stack

TypeScript · React · Vite · Tailwind CSS · shadcn/ui

## Getting started

```bash
npm install
npm run dev                     # http://localhost:8080 (or the port Vite prints)
npm run build                   # production build in dist/
```

## Project structure

`src/components` (Properties, Rentals, PropertyCalendar, ImageGallery, ...) · `src/pages` routes
